# 4.3.929 更新日志（926 之后累计）

版本：4.3.929（4030929）｜日期：2026-10-23

范围：4.2.926 → 4.3.929，汇总 4.3.927、4.3.928 和 4.3.929 的变化。

## 新增功能

- 漫画新增本地文字识别，可长按图片查看、复制原文；会员可开启“本书繁→简”，将纯色气泡中的繁体对白覆盖显示为简体，也可在文字页预览转换结果。
- 新增会员专享漫画超分：在 API 26 起且系统支持的设备上本地提升清晰度，支持长图分块处理，可与繁→简同时开启。
- 自定义主题分享 Beta：会员可导出、分享与导入 `.qytheme`，包含配色、部件选择、阅读排版及用户素材，导入前可预览。
- 本地导入新增未加密 MOBI6 支持，可提取目录、封面与插图；优化大体积 EPUB 的导入速度。
- 会员与账号页面整合，新增“我的权益”、礼包领取、点数充值和会员方案展示；支持会员昵称配色及终身会员动态头像。终身超级会员提供自定义字体与本地书籍云空间，以及专属“曜金藏书”主题，实际权益与开放时间以应用展示为准。
- 新增“霓港来信”主题；全局字体新增“跟随系统”，系统更换字体后回到应用即可生效。
- 新增“同步问题”记录页，便于定位同步失败、超限条目及云文件传输问题。
- 书架平铺新增“上次阅读置顶”的中、大样式；朗读面板新增“回到正文”；阅读页支持智感握姿悬浮按钮，目录可跳转书籍详情。
- 页眉、页脚可分别设置字号、不透明度、颜色与左右收缩；正文和正则样式支持九档字重，段首缩进可选择 0–4 字符。“我的”页新增显示模式切换入口。

## 阅读与界面优化

- 漫画图片边下载边显示，优先加载屏幕上的图片；当前章、预加载与全文缓存统一调度，单张失败不再阻塞整章。
- 阅读设置按作用范围分层，漫画有独立的阅读方式与画面设置页。
- 正文自动缓存设 256 MiB 上限，漫画图片缓存设 1 GiB 上限，可在设置中查看和清理；手动缓存章节不参与正文自动清理。
- 优化 3D 仿真翻页的跟手效果、折线、阴影与手势冲突；支持上下跨章连续滚动，上下边距调至 0 时正文更贴近页眉页脚。
- 搜索范围采用左右分栏选择面板，优化大量书源的选择；发现页书源选择样式统一，搜索与发现的列表／平铺偏好可持久保存。
- 二级页面顶栏随滚动收起，统一封面展示规则，优化沉浸材质、选色面板和会员权益页面。
- 更新十张功能介绍海报，说明书同步采用暖米白、莓红与青绿配色；更新本项目和内核子模块的 README 与书源开发文档。

## 书源能力

- 原生书源图片支持后台字节脚本解密、文件前缀 IV 与密钥编码；新增 `image.reorderStrips` 横条重排。
- 发现分类 `dynamicMenus` 支持脚本返回分类数组或“名称::地址”文本。
- 顶层动态请求头按当前请求作用域求值；动态变量选项不再因与静态列表不同而错误回退。
- 完善正文图片按需加载、请求头保留、解密与取消流程，单图失败显示具体原因；含失败图片的章节不会写入正文缓存。

## 问题修复

- 修复目录筛选后跳错章节、条漫点击翻屏跨章冲到章末、向上跨章衔接不自然等问题。
- 修复朗读停止按钮误暂停；蓝牙或有线耳机断开时自动暂停朗读。
- 修复段评面板绘制与返回异常、主题正则气泡未采用自定义颜色等问题。
- 修复书源置底状态持久化、短书源名显示不完整、书源菜单遮挡及封面圆角问题。
- 修复会员权益展示、充值后点数刷新、登录后云书籍与字体同步，以及超限同步条目的定位问题。
- 改进漫画竖排繁体对白的底色识别、邻列处理和特殊标点判断，减少漏转换。

## 功能边界

漫画 OCR 与繁→简在设备本地执行，需要系统 OCR 能力；复杂背景、艺术字和部分倾斜文字可能保留原样。日文、英文、韩文目前只识别原文，尚未提供中文翻译。主题包分享仍为 Beta，不同设备的分页可能不同。
