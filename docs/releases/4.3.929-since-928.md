# 4.3.929 更新日志（928 之后）

版本：4.3.929（4030929）｜日期：2026-10-23

范围：4.3.928 → 4.3.929，不包含 928 已发布的功能。

## 新增功能

- 漫画新增本地文字识别：长按图片查看、复制本页文字，支持取消与重新识别。
- 新增会员专享“本书繁→简”：在漫画画面设置中开启，自动将纯色气泡里的繁体对白覆盖显示为简体；支持文字预览，可与漫画超分一起使用，关闭后恢复原图。
- 自定义主题分享 Beta：会员可导出、分享与导入 `.qytheme` 主题包，携带配色、部件选择、阅读排版及用户素材，导入前可预览内容。
- 阅读页支持智感握姿悬浮按钮，目录可跳转书籍详情；“我的”页右上角新增显示模式切换。
- 页眉、页脚可分别设置字号、不透明度、颜色与左右收缩；段首缩进可选择 0–4 字符。

## 体验优化

- 漫画图片边下载边显示，优先处理可见图片，减少整章等待；当前章、预加载和全文缓存共享图片调度名额。
- 原生书源图片脚本支持横条重排，完善带请求头、解密图片的按需加载流程。
- 统一多处书籍封面的展示规则，并沿用书架设置。
- 更新会员权益展示和账号刷新入口；优化详情页顶栏收起、选色面板操作和沉浸光感关闭按钮。
- 更新应用介绍图、README、书源开发文档与说明书，说明书配色与新版海报统一。

## 问题修复

- 修复筛选目录后点击章节可能跳错位置的问题。
- 修复朗读设置中的停止按钮误执行暂停的问题。
- 修复段评面板绘制与返回操作异常。
- 修复主题正则气泡未正确采用自定义颜色的问题。
- 改进漫画竖排繁体对白的底色判断与邻列处理，减少气泡边缘及特殊标点导致的漏转换。

## 功能边界

漫画识别与繁→简在设备本地执行，需要系统 OCR 能力；复杂背景、艺术字和部分倾斜文字保留原样。日文、英文、韩文目前只识别原文，尚未提供中文翻译。主题包分享仍为 Beta，不同设备的分页可能不同。
