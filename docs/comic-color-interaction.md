# 彩色阅读交互设计

状态：已接入正式阅读器。当前实现说明见下文；后面的原始交互方案保留作为后续设计参考，不代表所有视觉细节均已实现。

实际入口为现有「画面设置」顶部的「AI着色」开关，按书保存，会员权限与超分一致。关闭开关恢复原图；长按单页着色不启用全书开关。画面设置不再显示状态文字、暂停／对比／更多按钮，正文上也不再显示「彩色阅读 · 会员」快捷浮层。会话层保留暂停、对比与重试能力供后续交互复用，当前设置界面不提供这些入口。

翻页模式处理当前跨页和后两跨页；条漫按可见画面中心排序，并沿滚动方向按图片高度估算约两屏的预取范围。挂载视图每 250ms 更新候选，最多保留 32 项；等待触摸、滚动停止 300ms 再启动新任务和显示新结果。任务串行，队列随视口替换；与超分共用计算队列。离开页面、换书、失去会员权限均不再发布旧任务结果。单张长宽比超过 4:1 的图片提示不支持、继续显示原图，不切块拼色。

回归脚本：scripts/comic-color-reading-check.mjs（真实会话类的优先级、跳转、暂停/关闭/对比、单页、会员、后台、跨书、触摸、重试与缓存失效），以及原有 comic-colorizer-check、comic-text-check、comic-image-pipeline-check。手机性能与布局以真机验收为准。

以下为原始交互方案及后续视觉参考。原型中的会员选择仅用于演示；正式功能不会模拟或修改会员授权。

## 会员权益

漫画着色与漫画超分采用同一会员口径：账号有效会员可用，不单独增加更高档位。复用 AccountSessionStore.activeMembershipSku()，沿用其有效期、限制状态和离线授权规则。

- 入口和面板显示「会员专享」，非会员仍可看到入口与功能说明，主操作为「开通会员」，进入现有 AccountCenter。不开默认试用，也不开始模型计算。
- 有效会员显示「开启彩色阅读」。按书保留开关偏好，但实际权限另行检查，不能用已保存的开关绕过会员校验。
- 排队出队、读取彩色缓存、启动推理和发布结果时检查权限。处理中到期或退出登录，不再接新任务；原生推理安全结束，迟到结果不能显示。
- 非会员不在阅读器中展示会员彩色缓存，恢复原图；缓存保留，续费后可复用。已主动保存到相册的图片不回收。
- 当前页面到期后显示「会员已到期，续费后恢复」，提供会员入口；未开通时显示「会员专享」。原图阅读不受影响。
- 会员开通返回后刷新权限，保留页码和阅读位置；首次开通由用户主动开启，已有书籍开关可在权限恢复后生效。
- 能力缺失优先提示设备不支持，不引导用户通过付费解决设备兼容性。

## 核心流程

阅读器工具栏「彩色阅读」 → 底部面板 → 开启 → 当前页先显示原图 → 完成后原位切换彩色 → 自动准备后面两页。翻页始终可用，不等待着色、不跳离阅读器、不改变阅读位置与缩放。

首次打开面板显示「当前页优先，提前准备后面两页。图片在本机处理，原图始终保留。」主按钮为「开启彩色阅读」。底部保留一行「颜色由 AI 推测，可能与原作不同」。之后进入直接显示任务状态，隐藏首次说明。

开关按书籍记忆，初始关闭。重新打开已开启的书籍，仅在阅读器前台启动任务。不开全局默认自动着色。

## 入口与界面

| 位置 | 交互 |
| --- | --- |
| 阅读器工具栏 | 「彩色阅读」，打开同一控制面板；开启时有选中状态 |
| 阅读器轻量状态入口 | 「正在着色第 6 页」「彩色阅读 · 已暂停」；点击打开面板。就绪后提示短暂显示并随工具栏隐藏 |
| 图片长按菜单 | 保留「本页着色」；仅处理当前图片，不隐式打开全书彩色模式。成功后留在阅读器显示该页彩色 |
| 控制面板 | 当前状态、当前页与后两页的状态、本页原图／彩色切换、暂停／继续、关闭彩色 |
| 已完成页面的面板 | 提供「保存本页彩色图」「分享」，与模式控制分层，避免四个大按钮常驻 |

原型为了方便体验保留了上一页／下一页按钮与状态入口。正式版沿用现有翻页手势、长按、单击呼出工具栏，不新增常驻翻页按钮，不覆盖内容触控区。原型的页码和任务是演示数据，翻页不会切换到其他漫画内容。

普通宽度采用底部面板。展开屏且有效宽度足够时使用右侧面板，漫画区域重新等比布局；宽度不足仍使用底部面板。折叠／展开保留任务、当前页、原图对比状态，避免重算。面板可收起，收起不暂停任务。点系统返回先收面板，再退出阅读器。

## 处理与显示规则

1. 任务范围为当前页及阅读顺序后两页，不是同时运行三个模型。同一时刻只进行一个着色推理。
2. 原图先加载，彩色结果准备并解码完成后再替换。尺寸、滚动锚点、缩放比例保持不变；手指拖动／缩放时延后切换到手势结束，避免画面跳动。
3. 优先级：用户点名的单页／可见当前页 → 阅读顺序下一页 → 后第二页。条漫多页可见时优先可见面积最大的页，其余可见页在预取页之前；进度文案必须指明正在处理的页。
4. 跳页时立即丢弃尚未启动的远处预取项。已进入原生计算的单页等待安全结束，然后优先新当前页。不要销毁仍在推理的 Worker。
5. 翻到未完成页立即显示原图。翻到已缓存页直接显示彩色，不重复推理。跨章预取仅限本地已可用的下一章图片；不因着色额外下载整章。
6. 「本页显示：原图／彩色」只切换当前页，不暂停队列、不关闭整本书的模式。比较原图时新结果不抢回彩色；离开该页后重置临时对比状态。
7. 生成中没有真实百分比：显示「正在着色第 N 页」，附近页分别显示「着色中／等待／已就绪」。不把模拟进度条或模型内部耗时展示给读者。

## 暂停、关闭与异常

| 状态／动作 | 对读者的表现 | 任务处理 |
| --- | --- | --- |
| 暂停着色 | 保留已完成页的彩色，未完成页显示原图；按钮变「继续着色」 | 不启动下一项。当前原生调用安全完成后可存缓存；不强制改变当前显示 |
| 继续着色 | 从当前阅读位置重新判断优先级 | 命中缓存直接用，不沿用远处旧队列 |
| 关闭彩色 | 立即恢复原图，书籍开关关闭；现有缓存保留 | 清空未开始项；在执行的调用安全退出，结果不能迟到覆盖界面 |
| 切书／退出阅读器 | 不显示着色完成弹窗、不发送通知 | 取消待处理项；停止后续任务，保留已完成缓存 |
| 切到后台／息屏 | 不承诺后台持续运行 | 暂停调度。回前台且书籍开关仍开时，从当前页恢复 |
| 单页失败 | 本页仍可阅读；面板显示「本页着色未完成 · 重试」 | 不无限自动重试，不阻断后面页面；点击重试只重试本页 |
| 图片下载失败 | 沿用阅读器图片重试提示 | 原图未就绪不进入模型队列，区分下载失败与着色失败 |
| 动图／超长条／能力缺失 | 显示明确原因；长条提示当前只支持普通漫画页 | 禁用该页启动入口，不能假装处理成功 |

「暂停」与「关闭」需要保持区别：前者暂停生成，后者同时恢复原图。不为两者弹确认框。相册权限只在用户点击保存时按系统流程申请；分享调用系统面板。

当前页着色、彩色显示、任务进度分别建模，避免一个布尔值混淆这些状态。初版不加入整章后台任务、参数调节、强度滑块或假定能改善效果的「重新随机配色」。

## 与现有能力衔接

- ComicColorizer 保留图片读取、模型验证、缓存、Worker 安全退出和 JPEG 处理。
- 新增阅读会话级调度器，持有开启／暂停状态、当前页、附近页及缓存结果。只向现有引擎提交一项任务，完成后再根据最新阅读位置选择下一项。
- ReaderComicImageItem 使用原图作为布局与失败兜底；彩色图是可切换显示层。避免每个挂载的图片项自行启动任务，从而把整章塞入队列。
- 图片已下载／解密后再交给着色，不二次下载同一页面。缓存仍使用图片内容与模型版本作为身份；URL 或书籍页码不能单独代表图片内容。
- 书籍开关进入现有阅读设置持久化体系；任务状态、对比原图状态留在阅读会话中。
- 着色、超分不能同时抢占同一页的大量内存。初版彩色显示优先于超分显示，保留原来的超分设置；关闭彩色后恢复原超分显示。是否将超分用于彩色结果，另行验证后再开放。
- 繁简转换与未来日／韩翻译使用原图坐标系，文字层放在当前图像之上。未来可组合为「原图／彩色」和「原文／中文」两项独立开关；本期不加入尚未实现的日／韩翻译入口。

## 验收场景

- 开启后仍能立即翻页；只有当前页及后两页进入准备范围，串行推理。
- 从第 5 页快速跳到第 20 页，未开始的第 6／7 页任务被移除；正在计算的任务结束后优先第 20 页。
- 彩色结果出现时不改变页码、滚动偏移、缩放比例；拖动中不切图。
- 切到「本页原图」后等待队列完成，仍保持原图；翻页后正常按彩色模式显示。
- 暂停后，已彩色页面保持彩色；关闭后全部恢复原图；再次开启命中缓存。
- 失败页可重试，后续页仍可处理；重复点击不能启动重复推理。
- 退出、切书或后台后没有迟到结果覆盖新页面，不能销毁尚有原生回调的线程。
- 折叠／展开、深浅主题、较大字号下可收起面板，按钮不重叠，漫画保持比例。
- 保存／分享目标是当前页彩色原始输出文件，不能误导出截图、原图或上一页结果。

实施顺序：会话调度与书籍设置 → 阅读器彩色显示层 → 面板和单页入口 → 生命周期与翻页压力验证。模型画质保持本次已接受的版本。
